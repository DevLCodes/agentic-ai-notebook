System designs

  • RAG · 10M documents · 50k users

    Enterprise Search Assistant

    An assistant that answers employee questions over Google Drive, Confluence and Jira while respecting who can see what. Covers ingestion, the knowledge base, hybrid retrieval, permissions, deployment, observability and evals.

  • Pipelines · 2M docs · 15-minute freshness

    Fresh Knowledge Base Pipeline

    Keeping a support agent’s knowledge base fresh as thousands of docs change daily. Covers change capture with Kafka, versioned chunk writes, deletes and permission changes, bursts, observability and safe re-embedding, with seven interactive 3D scenes.

  • RAG + structured data · SEC filings · built and measured

    FinSight: Research Assistant over SEC Filings

    Answering analyst questions from 10-Ks and 10-Qs with every number correct and cited. Ledger-driven EDGAR ingestion, parsing and chunking, pgvector, an XBRL path where the LLM plans and code computes, text retrieval and evals on FinanceBench, with seven interactive 3D scenes and real scores.

  • Agents with actions · 200k conversations/day

    AI Customer Support Agent with Actions

    A food-delivery support agent that answers questions and checks orders, cancels and refunds. Covers the one-minute picture, routing and the multi-agent trade-off, money rules in code, the pre-tool hook checks, prompt injection by design, and evals before and after launch, with six interactive 3D scenes.

  • Agents with actions · production incidents · 3-minute root cause

    AI On-Call Assistant

    Investigates production alerts and posts a root cause with evidence in Slack within 3 minutes, then suggests fixes that need approval. Covers dedup without an LLM, parallel investigation, an evidence gate in code, post-fix monitoring, and evals with real numbers, a shadow gate and a kill switch, with six interactive 3D scenes.

  • Text-to-SQL · BigQuery · 2,000 users

    “Ask Your Data” Analytics Agent

    Plain-English questions over an 800-table warehouse, answered with a number, a chart and one line. Covers schema retrieval without sample rows, running every query as the user, guards in code, execution accuracy, and production monitoring without labels: proxies, a weekly graded sample and rollback triggers, with six interactive 3D scenes.

  • Text-to-SQL + RAG · 5,000 account managers · suggestions only

    Ads Account Manager Assistant

    Answers advertiser questions like "why did my CPC go up?" from live BigQuery data, help docs and past notes, and suggests budget moves without applying them. Covers predefined tools instead of free SQL, per-advertiser isolation in code and the warehouse, a root-cause walkthrough, number checks, and how to tell if a suggestion is any good.
