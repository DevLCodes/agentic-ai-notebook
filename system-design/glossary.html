A

ACL (access control list)Governance
A list on a resource saying which users and groups may read or change it. Read more
AgentArchitecture
An LLM that decides its own next step in a loop, calling tools until a goal is met. Read more
Agentic RAGRetrieval
RAG where the model decides when and what to search, possibly several times, instead of a fixed retrieve-then-answer step. Read more
ANN (approximate nearest neighbour)Retrieval
Finding vectors that are almost certainly the closest without comparing against every vector; trades a little recall for big speed. Read more
Audit logGovernance
A tamper-resistant record of who asked what, which documents were used and what was answered. Read more

B

BackfillPipelines
A one-off job that loads everything that already exists, as opposed to processing new changes. Read more
Bi-encoderRetrieval
A model that embeds query and document separately so document vectors can be precomputed; used for retrieval. Read more
Blue-green deploymentDeployment
Running the new version beside the old one and switching traffic in one step, keeping the old one for instant rollback. Read more
BM25Retrieval
The standard keyword ranking formula: rewards rare query words that appear often in a document, with a length penalty. Read more

C

CalibrationEvals
A confidence score is calibrated when answers scored p are right about p of the time; raw cosine or rerank scores are not. Read more
Canary releaseDeployment
Sending a small share of traffic (say 5%) to a new version and watching metrics before rolling it out to everyone. Read more
Change data capturePipelines
Turning changes in a source system into a stream of events, here via webhooks and change feeds. Read more
ChunkKnowledge base
A passage of a document (typically 300 to 800 tokens) that is embedded, retrieved and quoted as one unit. Read more
Chunk overlapKnowledge base
Repeating the last bit of one chunk at the start of the next so a sentence cut at the boundary is not lost. Read more
CitationGeneration
A link from a claim in the answer to the source chunk that supports it. Read more
Citation launderingGeneration
Citing a real source, often with a real quote, for a claim it does not support; only an entailment check catches it. Read more
Citation precisionEvals
The share of individual citations that actually support the sentence they are attached to; over-citing lowers it. Read more
Citation recallEvals
The share of answer sentences fully supported by their citations taken together. Read more
Consumer groupPipelines
A set of workers sharing one position in a topic; separate groups read the same or different topics independently. Read more
Context windowModels
The maximum number of tokens a model can read in one request, prompt and retrieved chunks included. Read more
Cosine similarityRetrieval
Similarity measured as the angle between two vectors: 1 means same direction, 0 means unrelated. Read more
Cross-encoderRetrieval
A model that reads the query and one document together and outputs a relevance score; accurate but slow, so used for reranking. Read more

D

Dead-letter queuePipelines
Where messages that keep failing are parked with their error, so they can be inspected and replayed instead of blocking the stream. Read more
DebouncePipelines
Waiting until a burst of events goes quiet before acting, so 30 saves of one page cause one re-index. Read more
Dense retrievalRetrieval
Search by nearest embeddings; finds text with the same meaning even when the words differ. Also called semantic search. Read more

E

ECE (expected calibration error)Evals
The average gap between confidence and accuracy across score bins, weighted by how many answers fall in each bin. Read more
efSearchRetrieval
The beam width of an HNSW search: how many candidates stay open while walking the graph. Higher means better recall and slower queries. Read more
EmbeddingRetrieval
A list of numbers representing a piece of text, placed so that similar meanings sit close together. Read more
Embedding dimensionRetrieval
How many numbers each embedding has, commonly 384 to 3,072; drives storage and memory cost. Read more
EvalEvals
An automated test of model or system quality, run on a fixed set of inputs with known good outputs. Read more
Exact k-NNRetrieval
Comparing the query with every stored vector and keeping the k most similar. Perfect recall, cost grows with the corpus; the ground truth for judging ANN. Read more

F

Fail closedGovernance
When a safety check cannot decide, deny access rather than allow it. Read more

G

Golden setEvals
A curated list of real questions with correct answers and source documents, used as the regression suite. Read more
GroundednessEvals
Whether every claim in an answer is supported by the retrieved sources. Read more

H

HallucinationModels
A fluent, confident statement the sources do not support. Read more
Hard negativeModels
A training example that retrieval ranks highly but is not relevant, used to teach a reranker or embedder fine distinctions. Read more
HNSWRetrieval
Hierarchical navigable small world: a layered graph index for fast approximate nearest-neighbour search. Read more
Hybrid searchRetrieval
Running keyword and dense search together and fusing the results. Read more
Hybrid search alphaRetrieval
The weight in alpha·dense + (1−alpha)·keyword that sets the blend; 1 is pure vector search, 0 is pure keyword search. Read more

I

IdempotentPipelines
Safe to run more than once with the same result, so retries and replays cannot corrupt data. Read more
Identity provider (IdP)Governance
The central system that signs users in and knows their groups, such as Google Workspace or Okta. Read more
Ingestion lagPipelines
Time from an edit in the source to that edit being searchable. Read more
Inverted indexRetrieval
A map from each word to the documents containing it; the data structure behind keyword search. Read more
IVFRetrieval
Inverted file index: vectors grouped into clusters, and a query searches only the nearest clusters. Read more

K

Knowledge baseKnowledge base
Everything an assistant can search: documents, chunks, metadata and indexes, plus the pipeline that keeps them fresh. Read more
KV cacheModels
The attention keys and values kept for every token of every active request; it grows with context length × concurrent users. Read more

L

Late interaction (ColBERT)Retrieval
Stores one vector per token and scores with MaxSim (each query token’s best match, summed); between bi- and cross-encoders in cost and quality. Read more
Learning to rank (LTR)Retrieval
Training a model such as LambdaMART on labelled query–document pairs to weight ranking signals instead of hand-tuning them. Read more
LLMModels
Large language model: predicts text one token at a time; here it writes the final answer from retrieved chunks. Read more
LLM-as-judgeEvals
Using a model to grade outputs against a rubric; must be calibrated against human ratings. Read more

M

Metadata filterRetrieval
Restricting search to chunks whose fields match, such as region = India or a permission check. Read more
Mixture of experts (MoE)Models
An architecture that routes each token through a few expert sub-networks, so compute follows the active parameters and memory follows the total. Read more
MMR (maximal marginal relevance)Retrieval
Picking results one at a time, trading similarity to the query against similarity to what is already picked, so near-duplicates do not fill every slot. Read more
Model cascadeArchitecture
Trying a cheap model first and escalating to a stronger one only when a check on the answer fails. Read more
MRR (mean reciprocal rank)Evals
Average of 1 / rank of the first correct result; rewards putting the right document at the very top. Read more

N

nDCGEvals
Normalised discounted cumulative gain: scores a ranking by how high the relevant results sit, compared with the ideal order. Read more

O

Open-weight modelModels
A model whose trained parameters you can download and run on your own hardware, under a licence that may still restrict use. Read more
OpenTelemetryObservability
An open standard for traces, metrics and logs, so each step of a request can be timed and inspected. Read more

P

Partition keyPipelines
The field that decides which partition a message goes to; keying by doc_id keeps one document's events in order. Read more
PIIGovernance
Personally identifiable information, such as names, emails or ID numbers, to redact from logs and traces. Read more
Post-filterRetrieval
Applying a filter after search; a selective filter can leave too few results. Read more
Post-hoc attributionGeneration
Writing the answer first and attaching similar-looking sources afterwards, instead of citing from the given sources while generating. Read more
Pre-filterRetrieval
Applying a filter before or during search so ranking only considers matching items. Read more
PrincipalGovernance
An identity that can be granted access: a user, a group or a service account. Read more
Product quantisationRetrieval
Compressing vectors into short codes to save memory, with a small loss of accuracy. Read more
Prompt injectionGovernance
Text inside a document or input that tries to override the assistant's instructions. Read more

Q

QuantizationRetrieval
Storing vectors or model weights in fewer bits (float16, int8, 4-bit, binary or product codes) to cut memory; for vectors, usually followed by re-scoring a shortlist with full vectors. Read more
Query rewritingRetrieval
Turning the user's message into a better search query: standalone, with filters and expanded acronyms. Read more

R

RAG (retrieval-augmented generation)Retrieval
Retrieving relevant passages and giving them to the model so it answers from sources rather than memory. Read more
Recall@kEvals
How often the right document appears in the top k results. Read more
Recency decayRetrieval
A freshness boost 0.5^(age / half-life) that halves a document’s recency score every half-life; a soft boost, not a filter. Read more
Reciprocal rank fusion (RRF)Retrieval
Merging ranked lists by summing 1 / (60 + rank) per document; needs no score calibration. Read more
Reconciliation crawlPipelines
A periodic "what changed since my cursor" sweep that catches events webhooks missed. Read more
RerankingRetrieval
A second, more accurate scoring pass over the top candidates to put the best few first. Read more
RouterArchitecture
The component that decides which agent, model or tool handles a request, or whether to ask a clarifying question first. Read more

S

SafetensorsModels
A weight file format that stores plain tensors, so loading it cannot run code the way unpickling a .bin can. Read more
Score normalisationRetrieval
Rescaling each retriever’s scores to a common range (min-max or z-score) before adding them, because BM25 has no upper bound. Read more
Selective predictionEvals
Answering only above a confidence threshold, trading coverage for accuracy; the threshold comes from the cost of a wrong answer versus an escalation. Read more
Semantic chunkingKnowledge base
Splitting text where the topic shifts, found by comparing embeddings of neighbouring sentences. Read more
Semantic entropyEvals
Entropy over several sampled answers grouped by meaning; high values mean the model is guessing. Read more
Semantic routerArchitecture
A router that embeds the request and picks the route whose example requests are most similar, if the score clears a threshold and margin. Read more
Semantic searchRetrieval
Another name for dense retrieval: matching by meaning through embeddings. Read more
Small-to-big retrievalRetrieval
Searching small child chunks for precision, then sending their larger parent section to the model for context. Read more
Span and traceObservability
A span times one step; a trace is the tree of spans for one request. Read more
Sparse retrieval (learned)Retrieval
Models such as SPLADE that expand text into weighted keywords, mixing keyword speed with some synonym handling. Read more
StreamingDeployment
Sending the answer token by token as it is generated so the first words appear in about a second. Read more

T

Tenant isolationGovernance
Keeping one team's or customer's data unreachable by another, by filters or by separate indexes. Read more
TokenModels
The unit models read and bill by, roughly three quarters of an English word. Read more
Top-kRetrieval
Keeping the k highest-scoring results, for example top 50 from search and top 8 after reranking. Read more
Trajectory evalEvals
Grading the sequence of tool calls an agent made (which tools, order, arguments), not just its final answer. Read more

V

VectorRetrieval
A list of numbers; an embedding is a vector. Read more
Vector databaseRetrieval
A store that finds the nearest vectors to a query, usually with metadata filters. Read more

W

WebhookPipelines
An HTTP call a source system makes to you when something changes; a hint to re-read, not the data itself. Read more
Workflow (vs agent)Architecture
A fixed sequence of steps decided by code; cheaper and easier to test than an agent when the steps never change. Read more
