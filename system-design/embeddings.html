What an embedding is

An embedding turns a piece of text into a list of numbers so that texts with similar meaning get similar numbers.

The model was trained so that related passages end up near each other. That makes "find text that means the same thing" a geometry problem: embed the question, then find the nearest document vectors. This is dense or semantic search.

How similarity is measured

Three common measures: cosine similarity (angle), dot product (angle and length; equal to cosine when vectors are normalised) and Euclidean distance (straight-line distance). Use whichever the model was trained for; most text models expect cosine or dot product on normalised vectors.

Choosing an embedding model

FactorWhat to check
Quality on your dataRecall@k on your own golden questions beats any public leaderboard
Dimension384 to 3,072 is typical. More dimensions can capture more nuance but cost memory: 50M chunks × 768 floats ≈ 150 GB
Max input lengthText past the limit is cut off, so it caps your chunk size
Languages and domainMultilingual models for global companies; code or legal-tuned models if that is the content
Query vs document modeMany models embed questions and passages differently (a task type or prefix). Use the right one for each
Cost and hostingManaged API (such as Vertex AI text embeddings) vs a self-hosted open model on GPUs

Some models support shorter outputs (Matryoshka-style), letting you store 256 dimensions instead of 768 with a small quality loss.

Where embeddings struggle

  • Exact tokens. IDs, error codes, product SKUs and names blur together. Pair with keyword search.
  • Negation and numbers. "Policies that do not cover contractors" lands near "policies that cover contractors".
  • Very long text. One vector for a 40-page document averages away the details. Embed chunks, not documents.
  • New jargon. Internal acronyms the model never saw embed poorly. Query rewriting or a glossary expansion helps.

Versioning

Vectors from two different models are not comparable, even at the same dimension. Store embedding_model_version on every chunk. To upgrade, re-embed everything into a new index, evaluate it, then switch traffic. See re-embedding for the cost math.
