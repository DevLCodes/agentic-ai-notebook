3 · What should the loop do?

  
After every model call, the loop checks stop_reason. Pick one.

  

    

    

  


  

    

      Remember
      
    
        
  • Only end_turn means done. Every other stop_reason is continue or handle.
    • 
        
  • Tool results go back as role: "user", each echoing its tool_use_id.
    • 
        
  • Send the whole history every call, because the model is stateless.
    • 
      

    

    

      The 4 anti-patterns
      
    
        
  1. parsing text to detect tool calls or completion
    2. 
        
  2. a fixed iteration cap as the main stop condition
    3. 
        
  3. silently dropping turns to save tokens
    4. 
        
  4. tool_choice: "any" to force tools, so the loop never ends
