# Python practice

Python I practised while preparing for coding interviews. Everything runs with plain Python 3, no installs needed.

- [`interview_prep/`](interview_prep/): a 5-day plan of runnable lessons (lists, hash maps, stacks, trees, graphs, DP), practice problems with a test runner, and screening-style problems. Start with its [README](interview_prep/README.md).
- [`basics/`](basics/): first steps with operators, conditionals, lists, loops and `range`. `range.py` ends on purpose with a tuple assignment that raises `TypeError`, to show that tuples are immutable.

```bash
cd python-practice/interview_prep
python3 03_lists_arrays.py
```
